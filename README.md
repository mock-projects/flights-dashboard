# Flights Dashboard
This project is designed to show a web-based dashboard UI for upcoming flights at the airport.
Users can enter the dashboard, view flights by number, by airline, and by status (on-time, delayed, cancelled).
They can click into a flight to see specific details about that particular flight, as well.

## How to Run
Download the code, and then run:
1. `npm install`
1. `npm run dev`
1. Visit [`localhost:3000`](http://localhost:3000)

## How to Use
### Input Values
We can use `src/data/testData.mts` or `src/data/api-data.json` as the inputs for the dashboard.
By default, the project uses a downloaded copy of some API response data.

### Output
You'll see the outputs of this project in the browser; the data should be neatly presented for you!
